# Homebridge Go

Homebridge plugins, each published separately to npm:

- [homebridge-go-lutron](packages/lutron) for Lutron Caséta shades and Pico remotes over the local LEAP API
- [homebridge-go-venstar](packages/venstar) for Venstar thermostats
- [homebridge-go-wac-fans](packages/wac) for local WAC and Modern Forms fans
- [homebridge-go-yale](packages/yale) for Yale and August locks over local Bluetooth

## Development

Install [mise](https://mise.jdx.dev), then run `mise install` and `mise test`.
